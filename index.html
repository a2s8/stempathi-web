The ideas behind the game

Keep both sides equal.

−

Remove the same amount

x + 3 = 8 → x = 5

Remove three positive blocks from each pan. These cards explain the concept; the recording below covers division.

+

Add the same amount

x − 2 = 3 → x = 5

Add two to each side. On the left, each positive and negative pair has a total of zero.

÷

Compare equal shares

2x = 8 → x = 4

Make two equal groups on each pan. One x balances four units. Press Play to see the recorded sequence.
